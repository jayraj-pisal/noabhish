# Study Sphere

Your Role: Act as a senior full-stack web developer, UI/UX designer, and education-product architect specializing in modern student productivity platforms.

Short basic instruction: Build a modern, responsive study and resource-sharing website for students and friends. The platform should make it easy to share study materials, organize daily tasks, plan study sessions, and collaborate online.

What you should do:

Create a complete study platform with a clean, modern, student-friendly interface.

Add user registration and login.

Create a personalized dashboard showing today's tasks, upcoming study sessions, recent notes, and useful study statistics.

Add a Notes/Resources section where users can upload, view, download, organize, and share study materials.

Support useful file types such as PDF, DOC/DOCX, PPT/PPTX, images, and other common study files.

Allow resources to be organized by subject, topic, semester, or category.

Add a Daily Tasks feature where students can create, edit, complete, delete, and prioritize tasks.

Add a Study Planner with a calendar and scheduled study sessions.

Allow users to set deadlines, reminders, and study goals.

Add an online meeting/study-room feature where students can create or join study sessions with friends.

Add a simple group/chat or discussion feature for collaboration.

Add search and filtering for study resources.

Add user profiles showing shared resources and basic study information.

Add notifications/reminders for tasks, deadlines, and upcoming study sessions.

Make the dashboard useful at a glance rather than overcrowded.

Include responsive layouts for desktop, tablet, and mobile.

Add loading states, empty states, error messages, form validation, and success notifications.

Use reusable components and a well-organized project structure.

Build the required backend, database, authentication, file storage, and APIs rather than creating only a static frontend.

Make permissions secure so users can only perform actions they are authorized to perform.

Your Goal: Create an easy-to-use student study hub where students and friends can share study resources while managing their daily tasks and study schedules from one place.

Result:

Deliver a polished, production-quality web application.

Start with a visually impressive landing/login experience.

After login, provide a personalized dashboard.

Use a modern academic aesthetic with clean cards, intuitive navigation, good typography, subtle animations, and an accessible color palette.

Include these primary navigation sections:

Dashboard

Notes & Resources

Daily Tasks

Study Planner

Online Study Rooms

Messages/Groups

Profile

Make the Daily Tasks and Study Planner especially prominent because they are core features.

Include realistic sample data so the interface looks complete during development.

Ensure the application works smoothly on both mobile and desktop.

Clearly explain any environment variables, database setup, storage configuration, or third-party services required to run the project.

Constraint:

The target audience is students and friends.

Prioritize simplicity and usability over unnecessary features.

Do not make the interface look like a generic corporate dashboard.

Keep the design modern, friendly, focused, and suitable for studying.

Use secure authentication and authorization.

Do not expose private uploaded files or user information publicly without permission.

Design the architecture so additional features can be added later.

If a feature such as real-time video meetings requires an external service/API, use an appropriate integration and clearly identify what needs to be configured.

Avoid fake functionality: important buttons and workflows should actually work.

Context:
This website is intended to be a shared study platform for students and friends. The main purpose is to share study resources and help students stay organized. The most important features are Daily Tasks and the Study Planner, while notes/resources, online meetings, and collaboration should make the platform useful as a complete study hub.

Before implementing, first determine the recommended technology stack and application architecture for Caffeine AI. Then build the application in logical stages, ensuring that the frontend, backend, database, authentication, file uploads, and core workflows are properly connected.
